# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to [mun01180@gmail.com](mailto:mun01180@gmail.com).

Include the affected URL or file, a short description of the impact, and reproducible steps when possible. Please do not publish credentials, personal data, or an exploit proof in a public issue.

This repository is a static Jekyll site. Reports involving GitHub Actions, third-party scripts, embedded products, or the published site are all welcome.
