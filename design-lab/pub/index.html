Portfolio hub proposal

구축 사례는 과장보다 범위와 증거가 먼저 보이게 합니다.

`/portfolio/`는 얇은 허브입니다. 전체 상세 페이지를 흉내 내지 않고 대표 사례 4개를 problem, scope, architecture, evidence 단위로 압축해서 보여줍니다.

Portfolio trust model
  • 실제 구현 범위를 먼저 쓰고, 역할과 산출물을 분리합니다.

상세 페이지는 같은 템플릿으로만 확장합니다.

지금 단계의 `/portfolio/`는 허브입니다. 상세 페이지를 만들 때는 아래 순서를 고정해 신뢰와 보안 검토를 같이 통과시킵니다.

01 Intro

프로젝트 한 줄 정의, 역할, 기간 범위를 먼저 제시합니다.

02 Problem

왜 만들었는지, 어떤 병목이나 불신을 줄였는지 설명합니다.

03 Scope & Build

구현한 것과 구현하지 않은 것을 분리해서 적습니다.

04 Architecture

입력, 처리, 출력, 운영 경계를 blueprint 슬롯으로 보여줍니다.

05 Evidence + Mask

캡처, 로그, 링크를 민감 정보 제거 상태와 함께 제시합니다.
